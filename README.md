# 📧 Laravel Resend Email Integration - Order Management System

A modern **E-Commerce Order Management Dashboard** built with **Laravel 12** that integrates **Resend API** for instant transactional email receipts. This application demonstrates real-time email delivery with professional email templates.

## 🔑 Resend API Configuration

### Step 1: Create Resend Account

1. Visit [Resend.com](https://resend.com)
2. Sign up for a free account
3. Verify your email address

### Step 2: Get Your API Key

1. Log in to your Resend dashboard
2. Navigate to **API Keys** section
3. Click **Create API Key**
4. Copy your API key (starts with `re_`)

### Step 3: Configure Laravel

Update your `.env` file with Resend credentials:

```env
MAIL_MAILER=resend
RESEND_API_KEY=re_YOUR_ACTUAL_API_KEY_HERE
MAIL_FROM_ADDRESS=onboarding@resend.dev
MAIL_FROM_NAME="${APP_NAME}"
```

**⚠️ Important Notes:**
- Replace `re_YOUR_ACTUAL_API_KEY_HERE` with your actual Resend API key
- Free tier: 100 emails/day, 3,000 emails/month
- Use `onboarding@resend.dev` for testing (verified by default)
- For production, add and verify your own domain

### Step 4: Verify Domain (Production Only)

For production emails from your own domain:

1. Go to Resend Dashboard → **Domains**
2. Click **Add Domain**
3. Enter your domain (e.g., `yourdomain.com`)
4. Add the provided DNS records to your domain registrar
5. Wait for verification (usually 24-48 hours)
6. Update `MAIL_FROM_ADDRESS` to your domain email

### 2️⃣ Order Controller (`app/Http/Controllers/OrderController.php`)

```php
<?php

namespace App\Http\Controllers;

use App\Models\Order;
use App\Mail\OrderReceiptMail;
use Illuminate\Support\Facades\Mail;

class OrderController extends Controller
{
    public function index()
    {
        $orders = Order::latest()->get();
        return view('orders.index', compact('orders'));
    }

    public function sendReceipt($id)
    {
        $order = Order::findOrFail($id);

        // Change 'example@gmail.com' to your email address
        Mail::to('example@gmail.com')->send(new OrderReceiptMail($order));

        return redirect()->back()->with('success', "Receipt for {$order->order_no} sent successfully!");
    }
}
```

**📝 Note:** Update `example@gmail.com` to your actual email address for testing.

### 4️⃣ Mailable Class (`app/Mail/OrderReceiptMail.php`)

```php
<?php

namespace App\Mail;

use Illuminate\Bus\Queueable;
use Illuminate\Mail\Mailable;
use Illuminate\Mail\Mailables\Content;
use Illuminate\Mail\Mailables\Envelope;
use Illuminate\Queue\SerializesModels;
use App\Models\Order;

class OrderReceiptMail extends Mailable
{
    use Queueable, SerializesModels;

    public Order $order;

    public function __construct(Order $order)
    {
        $this->order = $order;
    }

    public function envelope(): Envelope
    {
        return new Envelope(
            subject: 'Your Order has been Confirmed! 🛒 # ' . $this->order->order_no,
        );
    }

    public function content(): Content
    {
        return new Content(
            view: 'emails.receipt',
        );
    }
}
```

## 🔐 Security Best Practices

### 1. Protect API Keys
```env
# ❌ BAD - Never commit actual keys
RESEND_API_KEY=re_actual_key_here

# ✅ GOOD - Use placeholder in version control

```

### 2. Add Rate Limiting
```php
// app/Http/Controllers/OrderController.php

use Illuminate\Support\Facades\RateLimiter;

public function sendReceipt($id)
{
    // Limit to 5 emails per minute per IP
    if (RateLimiter::tooManyAttempts('send-email:'.request()->ip(), 5)) {
        $seconds = RateLimiter::availableIn('send-email:'.request()->ip());
        return back()->with('error', "Too many emails. Try again in {$seconds} seconds.");
    }
    
    RateLimiter::hit('send-email:'.request()->ip(), 60);
    
    $order = Order::findOrFail($id);
    Mail::to('example@gmail.com')->send(new OrderReceiptMail($order));
    
    return back()->with('success', "Receipt sent!");
}
```

### 3. Validate Email Addresses
```php
// app/Http/Controllers/OrderController.php

public function sendReceipt(Request $request, $id)
{
    // If email comes from form input
    $request->validate([
        'email' => 'required|email|max:255'
    ]);
    
    $order = Order::findOrFail($id);
    Mail::to($request->email)->send(new OrderReceiptMail($order));
    
    return back()->with('success', 'Receipt sent!');
}
```

## ❓ Frequently Asked Questions (FAQ)

### Q1: Can I use Gmail instead of Resend?
**A:** Yes, but Resend is recommended for transactional emails. To use Gmail:
```env
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=your@gmail.com
MAIL_PASSWORD=your_app_password
MAIL_ENCRYPTION=tls
```
**Note:** You need to generate an App Password from Google Account settings.

### Q2: How do I change the recipient email dynamically?
**A:** Modify the controller to send to the customer's email:
```php
Mail::to($order->customer_email)->send(new OrderReceiptMail($order));
```

### Q3: Is Resend free?
**A:** Yes! Free tier includes:
- 100 emails per day
- 3,000 emails per month
- Perfect for testing and small projects

### Q4: Can I send emails to multiple recipients?
**A:** Yes:
```php
Mail::to($order->customer_email)
    ->cc('admin@example.com')
    ->bcc('sales@example.com')
    ->send(new OrderReceiptMail($order));
```

### Q5: How do I add email attachments?
**A:** Add the `attachments()` method in your Mailable:
```php
public function attachments(): array
{
    return [
        Attachment::fromPath(storage_path('app/invoice.pdf')),
    ];
}
```

### Q6: Can I customize the email template colors?
**A:** Yes! Edit `resources/views/emails/receipt.blade.php` and change the inline styles:
```html
<!-- Change header color from #1a1a1a to blue -->
<div style="background-color: #0066cc; ...">
```

### Q7: How do I test emails locally without sending?
**A:** Use log driver:
```env
MAIL_MAILER=log
```
Emails will be saved to `storage/logs/laravel.log` instead of sending.

### Q8: What if I exceed the daily email limit?
**A:**
- Free tier: 100/day
- Upgrade to paid plan for higher limits
- Or use queue system to spread emails over time

### Q9: Can I schedule emails?
**A:** Yes, use Laravel's queue delay:
```php
Mail::to($email)
    ->later(now()->addMinutes(30), new OrderReceiptMail($order));
```

### Q10: How secure is Resend API?
**A:** 
- ✅ Industry-standard TLS encryption
- ✅ API key authentication
- ✅ No email content stored on servers
- ✅ GDPR compliant

### Q11: Can I track if emails were opened?
**A:** Yes, Resend provides email analytics in their dashboard:
- Delivery status
- Open rates (with tracking pixel)
- Click tracking
- Bounce rates

### Q12: What's the difference between `send()` and `queue()`?
**A:**
- `send()` - Sends immediately (blocks request)
- `queue()` - Adds to queue (faster response, processed in background)

### Q13: How do I handle email failures?
**A:** Use try-catch:
```php
try {
    Mail::to($email)->send(new OrderReceiptMail($order));
    return back()->with('success', 'Email sent!');
} catch (\Exception $e) {
    return back()->with('error', 'Email failed: ' . $e->getMessage());
}
```

### Q14: Can I use this in production?
**A:** Yes! Just:
1. Set `APP_ENV=production`
2. Set `APP_DEBUG=false`
3. Use your own verified domain
4. Add proper security measures

### Q15: How do I add multiple products to one email?
**A:** Modify the Order model to have a relationship with OrderItems:
```php
// Add products array to order
$order->products = [
    ['name' => 'MacBook', 'price' => 199999],
    ['name' => 'iPhone', 'price' => 149900]
];
```
